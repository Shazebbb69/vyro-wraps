# Vyro Wraps

Premium fitness e-commerce platform for Vyro Wraps (Self-Applying Lifting Straps).

## Project Structure

This project is separated into two main applications:

- `frontend/`: Next.js (App Router) application serving the D2C e-commerce experience.
- `backend/`: Node.js/Express.js backend scaffold for future API development.

## Tech Stack

**Frontend**
- Next.js
- TypeScript
- Tailwind CSS
- Framer Motion
- Lucide React

**Backend**
- Node.js
- Express.js
- TypeScript

## Running the Frontend

```bash
cd frontend
npm install
npm run dev
```

Visit `http://localhost:3000` to view the application.
